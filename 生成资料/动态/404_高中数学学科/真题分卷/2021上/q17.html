30 分
"等比数列前n项和公式"是普通高中数学教学的重要内容，请完成下列任务：
(1) 设计一组问题，说明学习"等比数列前n项和公式"的重要性；（10分）
(2) 写出等比数列前n项和公式，并给出两种不同的推导方法；（10分）
(3) 针对其中一种推导方法写出教学过程。（10分）
🏆 满分版

(1) 设计问题组说明学习等比数列前n项和的重要性

设计如下递进问题组：

  • 问题1（生活情境）：某种细菌每分裂一次数量翻倍，初始有1个细菌，分裂10次后共有多少个细菌？（列出算式：1+2+4+…+2⁹=?）
  • 问题2（引出需求）：上述算式是等比数列求和，逐项相加可行吗？如果分裂100次呢？有没有简便公式？
  • 问题3（知识联系）：我们已学了等比数列的通项公式，能否利用通项的特征找到求和的方法？
  • 问题4（应用价值）：储蓄复利、传染病传播、折旧计算中都涉及等比数列求和，掌握公式能解决哪些实际问题？

通过这组问题，从生活实例引出求和需求，激发探究动机，体现等比数列求和公式的现实意义和应用价值。

(2) 公式及两种推导方法

公式：等比数列 {aₙ}（公比 q），前 n 项和 Sₙ = a₁(1-qⁿ)/(1-q)（q≠1）；当 q=1 时，Sₙ=na₁。

方法一：错位相减法。

Sₙ = a₁ + a₁q + a₁q² + … + a₁qⁿ⁻¹ ……①

qSₙ = a₁q + a₁q² + … + a₁qⁿ ……②

①-②：(1-q)Sₙ = a₁ - a₁qⁿ = a₁(1-qⁿ)，所以 Sₙ = a₁(1-qⁿ)/(1-q)（q≠1）。

方法二：利用等比定理（提取公比法）。

Sₙ = a₁ + a₁q + a₁q² + … + a₁qⁿ⁻¹ = a₁(1 + q + q² + … + qⁿ⁻¹)。

令 T = 1 + q + q² + … + qⁿ⁻¹，则 qT = q + q² + … + qⁿ，T - qT = 1 - qⁿ，T = (1-qⁿ)/(1-q)（q≠1）。

所以 Sₙ = a₁·(1-qⁿ)/(1-q)。

注：两种方法本质相同（都是利用等比数列"乘q后错位"的特征消去中间项），但切入点不同：方法一直接对 Sₙ 操作，方法二先提取 a₁ 再处理。

(3) 错位相减法的教学过程

  • 环节一：回顾引入
    教师回顾等比数列定义和通项公式，提出问题：如何求 Sₙ=a₁+a₁q+…+a₁qⁿ⁻¹？引导学生观察等比数列的特征——每项乘q得下一项。
    设计意图：从已有知识出发，引导学生发现等比数列的结构特征，为探究错位相减法做铺垫。
  • 环节二：探究推导
    教师提问：既然每项乘q得下一项，能否利用这一关系？组织学生讨论。学生尝试：两边乘q得 qSₙ，与原式错位相减，中间项全部消去，只剩 a₁ 和 a₁qⁿ，得到 (1-q)Sₙ=a₁(1-qⁿ)。
    设计意图：学生经历"观察特征→尝试方法→推导公式"的完整过程，体会错位相减法的巧妙，发展逻辑推理与数学运算素养。
  • 环节三：归纳讨论
    教师引导学生整理公式 Sₙ=a₁(1-qⁿ)/(1-q)（q≠1），讨论 q=1 的特例（Sₙ=na₁）。
    设计意图：分类讨论q=1的特例，培养严谨思维。
  • 环节四：巩固应用
    练习：求具体等比数列的前n项和，首尾呼应解决问题1中的细菌数量问题。
    设计意图：巩固公式应用，首尾呼应。

  • ② 定框架：问①——从生活实例（细胞分裂、传染病传播、储蓄复利）设计递进问题组，引出求和需求。问②——公式 Sₙ=a₁(1-qⁿ)/(1-q)（q≠1），两种方法：①错位相减法（S与qS错位相减）；②分组求和法/等比定理法（利用等比性质）。问③——选错位相减法写教学过程。

🎯 考场版

(1) 问题组：①细菌分裂10次共多少个？(1+2+…+2⁹=?) ②逐项相加可行吗？100次呢？有无公式？③能否利用通项特征求和？④复利、传播等实际问题中如何应用？

(2) 公式：Sₙ=a₁(1-qⁿ)/(1-q)（q≠1），q=1时Sₙ=na₁。

方法一·错位相减法：S=a₁+…+a₁qⁿ⁻¹①，qS=a₁q+…+a₁qⁿ②，①-②得(1-q)S=a₁(1-qⁿ)→S=a₁(1-qⁿ)/(1-q)。

方法二·提取公比法：S=a₁(1+q+…+qⁿ⁻¹)，令T=1+q+…+qⁿ⁻¹，qT=q+…+qⁿ，T-qT=1-qⁿ→T=(1-qⁿ)/(1-q)→S=a₁(1-qⁿ)/(1-q)。

(3) 教学过程（错位相减法）：

  • 引入：回顾通项，提出求和问题，引导观察"乘q得下一项"特征。意图：铺垫。
  • 探究：两边乘q→错位相减→中间项消去→(1-q)S=a₁(1-qⁿ)。意图：探究发现，发展运算素养。
  • 归纳：整理公式+讨论q=1特例。意图：培养严谨思维。
  • 巩固：求具体数列和+解决细菌问题。意图：巩固应用，首尾呼应。

🛟 救急版

(1) 问题组：细菌分裂→逐项加太慢→有无公式→实际应用。
(2) S=a₁(1-qⁿ)/(1-q)（q≠1）。法一错位相减（S-qS消中间项）；法二提取公比（令T=1+q+…+qⁿ⁻¹）。
(3) 引入→探究（乘q错位相减）→归纳（公式+q=1特例）→巩固。意图：探究发现。

💡 得分技巧

  • 问①问题组必须递进：生活实例→引出需求→知识联系→应用价值，不能平行提问；
  • 问②两种方法必须不同：错位相减法 + 提取公比法（或等比定理法），不能写两个一样的；
  • 公式必须讨论q=1特例（S=na₁），不讨论扣分；
  • 问③每个环节都要写"设计意图"；
  • 核心得分词：错位相减、中间项消去、乘q得下一项。
