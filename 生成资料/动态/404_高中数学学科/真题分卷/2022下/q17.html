材料是某高中数学教材"椭圆及其标准方程"一节的内容片段：取一条定长细绳，两端固定在图板两点F₁、F₂，套上铅笔拉紧绳子移动笔尖画出轨迹——椭圆。定义：平面内与两个定点F₁、F₂的距离的和等于常数（大于|F₁F₂|）的点的轨迹叫椭圆。完成下列任务：
(1) 写出椭圆标准方程的推导过程（设椭圆的焦距为2c，绳长为2a，焦点在x轴上）；（10分）
(2) 根据材料设计这部分内容的教学设计，包括教学目标、教学重点、教学过程（含引导学生研究的活动和设计意图）。（20分）
🏆 满分版

(1) 椭圆标准方程的推导过程

设椭圆焦距为 2c（c>0），绳长为 2a（a>c>0），焦点在 x 轴上。

建系设点：以 F₁F₂ 的中点为原点，F₁F₂ 所在直线为 x 轴建立直角坐标系。则 F₁(-c,0)、F₂(c,0)。设椭圆上任一点 M(x,y)。

列条件：由椭圆定义，|MF₁|+|MF₂|=2a，即：

√((x+c)²+y²) + √((x-c)²+y²) = 2a ……①

化简：将一个根号移到右边：

√((x+c)²+y²) = 2a - √((x-c)²+y²)

两边平方：

(x+c)²+y² = 4a² - 4a√((x-c)²+y²) + (x-c)²+y²

整理得：4cx = 4a² - 4a√((x-c)²+y²)

即：a√((x-c)²+y²) = a² - cx ……②

两边再平方：

a²((x-c)²+y²) = (a²-cx)²

展开：a²x² - 2a²cx + a²c² + a²y² = a⁴ - 2a²cx + c²x²

整理得：(a²-c²)x² + a²y² = a²(a²-c²)

因为 a>c>0，所以 a²-c²>0，令 b²=a²-c²（b>0），得：

b²x² + a²y² = a²b²

两边同除以 a²b²，得椭圆标准方程：

x²/a² + y²/b² = 1（a>b>0）

(2) 教学设计

  • 教学目标：
    ①知识与技能：掌握椭圆的定义和标准方程，能运用定义和方程解决简单问题。
    ②过程与方法：通过动手实验和方程推导，体会数形结合与化归思想，发展直观想象与数学运算素养。
    ③情感态度与价值观：在动手实践中感受数学美，激发探究兴趣。
  • 教学重点：椭圆的定义及标准方程的推导。
  • 环节一：情境引入（绳绳实验）
    教师活动：教师让同桌两人合作，用细绳和图钉在纸上画椭圆——将绳两端固定在两点，笔尖拉紧绳子移动。
    学生活动：学生动手实验，观察画出的轨迹形状，思考笔尖满足的几何条件。
    设计意图：动手实验激发兴趣，让学生直观感受椭圆的形成过程，为归纳定义做铺垫。
  • 环节二：定义归纳
    教师活动：教师提问：笔尖移动过程中，什么保持不变？笔尖到两个定点的距离之和等于什么？组织学生讨论。
    学生活动：学生发现绳长不变，即|MF₁|+|MF₂|=定值2a。教师引导归纳椭圆定义：平面内与两定点距离之和等于常数（大于|F₁F₂|）的点的轨迹。
    设计意图：从实验中归纳定义，体现"实践→理论"的认知过程。
  • 环节三：方程推导
    教师活动：教师提出目标问题——如何建立椭圆的方程？组织学生讨论建系方法，按"建系设点→列条件→坐标化→化简"步骤推导。
    学生活动：学生选择以F₁F₂中点为原点建系，写出|MF₁|+|MF₂|=2a，在教师引导下两次平方消根号，化简得标准方程。
    设计意图：学生经历完整的方程推导过程，掌握坐标法求曲线方程的通法，发展数学运算素养。
  • 环节四：巩固应用
    教师活动：展示练习题，引导学生运用定义和方程解题。
    学生活动：练习1——已知a、b求标准方程；练习2——判断点是否在椭圆上。
    设计意图：巩固定义和方程，及时反馈。
  • 环节五：小结作业
    小结：总结椭圆定义、标准方程及推导方法。
    作业：完成课后练习，思考焦点在y轴上的标准方程。
    设计意图：再巩固，拓展思维。

🎯 考场版

(1) 推导：F₁(-c,0), F₂(c,0)，设M(x,y)。由|MF₁|+|MF₂|=2a：√((x+c)²+y²)+√((x-c)²+y²)=2a。移项平方→整理→再平方→(a²-c²)x²+a²y²=a²(a²-c²)。令b²=a²-c²，得 x²/a²+y²/b²=1（a>b>0）。

(2) 教学设计

  • 教学目标：①掌握定义和标准方程；②通过实验和推导体会数形结合，发展运算素养；③感受数学美。
  • 教学重点：椭圆定义及标准方程推导。
  • 绳绳实验引入：用细绳画椭圆。意图：动手激发兴趣。
  • 定义归纳：发现|MF₁|+|MF₂|=定值→归纳定义。意图：实践→理论。
  • 方程推导：建系设点→列条件→化简→标准方程。意图：掌握坐标法通法。
  • 巩固应用：已知a,b求方程+判断点在椭圆上。意图：巩固反馈。
  • 小结作业：总结+思考y轴标准方程。意图：再巩固。
