404 高中数学·面试指南

面试＝结构化5min(2题)＋试讲10min＋答辩5min；备课室20min写教案简案。本页含流程·评分·结构化7类框架·试讲要点·教材7模块速览，每天计划里的任务点进来就能看具体内容。

一、面试流程与评分标准

流程（约40min）

抽题（题库随机）→ 备课室 20min 写教案简案 → 面试室：①结构化问答 5min(2题，考官读题) → ②试讲 10min(无生模拟讲课) → ③答辩 5min(考官围绕试讲提问) → 擦黑板退场。

评分（8维度100分，常简并为5项测评）

维度分值看什么
职业认知5教育/学生/教师观、师德
心理素质5情绪稳定、抗压、自信
仪表仪态5教态自然、着装得体
言语表达15清晰、流畅、准确
思维品质15逻辑严密、应变敏锐
教学设计10目标、重难点、环节完整
教学实施35学生主体、方法灵活、互动提问 —— 拉开差距的主战场
教学评价10反馈、改进、分层评价

5项测评归类：①职业认知 ②心理仪表(心理+仪表) ③表达思维(言语+思维) ④教学(设计+实施+评价) ⑤综合。试讲实施35分占比最大——试讲练好最划算。

得分铁律

  • 结构化：总—分—总，先表态再分3点再总结升华；
  • 试讲：全程学生主体(多互动提问)，表达流畅有热情，板书工整，突出数学思想方法；
  • 答辩：不抬杠、虚心接纳，被问住坦诚反思。

二、结构化7类答题框架

总模板：表态(一句话) ＋ 分点(3点，关键词＋一句话) ＋ 总结(升华)。每类侧重如下：

① 职业理念类（教育观/学生观/教师观/师德）

特征：问"你怎么看某教师做法/某教育现象"。

框架：判定符合/违背XX观 → 析材料对应点 → 总结践行。

万能句："该教师做法符合/违背素质教育观(以人为本学生观/新课改教师观)，值得学习/应改进。"

② 学生问题类（厌学/作弊/冲突/早恋）

特征：问"某学生出现XX问题怎么办"。

框架：了解原因(耐心沟通) → 针对性帮扶(因材施教) → 家校配合持续关注。

万能句："先了解背后原因，尊重学生，因材施教，家校合力。"

③ 课堂突发类（打断/纪律/失误）

特征：问"课堂上出现XX突发状况怎么办"。

框架：冷静化解(不中断教学) → 借机生成(把意外变资源) → 课后反思。

万能句："沉着冷静，维护课堂秩序，必要时借机生成教育契机。"

④ 班主任工作类（班风/活动/评优）

特征：问"作为班主任如何开展XX"。

框架：目标定位 → 具体举措(民主管理/活动育人/个别引导) → 总结预期。

万能句："以学生为主体，民主管理，开展丰富活动，形成良好班风。"

⑤ 家校沟通类（家长投诉/配合）

特征：问"家长XX你怎么办"。

框架：倾听理解 → 客观沟通(不卑不亢) → 协同解决。

万能句："尊重家长，耐心倾听，平等沟通，形成家校合力。"

⑥ 时政教育类（教育政策/热点）

特征：问对某政策/热点的理解。

框架：表态支持 → 谈意义(结合教育) → 落实到行动。

万能句："该政策体现了XX，作为教师应积极贯彻、身体力行。"

⑦ 综合逻辑类（计划组织/应变）

特征：组织活动/应变事件。

框架：事前(计划/准备) → 事中(组织/应变) → 事后(总结/反思)。

万能句："事先周密准备，事中灵活实施，事后认真反思。"

三、试讲10分钟要点

流程分配（控时是命门）

环节时长做什么
导入1min情境/旧知/设问引课题
新授5min探究/讲解/师生互动(假想学生回答)
巩固2min分层练习，点学生板演
小结1min由学生总结，教师升华
作业+板书1min分层作业；板书工整贯穿

备课20min写简案

按 教学设计五环节：导入／讲授新授／巩固练习／课堂小结／布置作业 ＋ 教学目标·重难点。模板见 404主观题框架·四、教学设计。

试讲评分要点（对应教学实施35分）

  • 学生主体——多提问互动，假想学生回答并反馈；
  • 数学逻辑清晰——突出数学思想方法(如数形结合、分类讨论)；
  • 板书工整、表达流畅有热情；
  • 核心素养落地——抽象/推理/建模/直观/运算/数据其一显性体现。

四、高中数学7模块重点速览（可试讲课题）

每个模块给核心知识点＋可试讲课题，试讲选题选自己把握的。

必修一·函数概念与性质

核心：函数定义(集合对应)、单调性/奇偶性/周期性、指对幂函数。

可试讲：函数单调性概念、指数函数图象与性质、奇函数图象关于原点对称。

必修二·平面解析几何

核心：直线方程、圆、椭圆/双曲线/抛物线。

可试讲：直线的斜率、椭圆标准方程、点到直线距离。

必修一·三角函数

核心：三角函数定义/图象/性质、恒等变换、解三角形。

可试讲：正弦函数图象、两角和公式、正弦定理。

必修二·数列

核心：等差/等比数列通项与求和、递推。

可试讲：等差数列通项公式、等比数列求和、错位相减法。

必修三·概率统计

核心：古典概型、随机变量分布、抽样估计、回归。

可试讲：古典概型、正态分布、用样本估计总体。

选修·导数及其应用

核心：导数定义/运算、用导数研究单调、极值、最值。

可试讲：导数的几何意义、用导数求单调区间、函数最值应用题。

必修二·空间立体几何

核心：空间点线面位置关系、线面平行/垂直、空间向量、体积。

可试讲：线面垂直判定定理、二面角、柱锥体积。

提示：结构化背"总—分—总"；试讲五环节严格控时；教材试讲课题选自己最把握的。考前一周至少2次全程模拟练时间感。
