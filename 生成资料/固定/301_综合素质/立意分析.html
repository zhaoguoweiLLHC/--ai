🎯 按立意类型归类（遇新题先认类型）　10 期真题归 6 类，同类套路通吃

类型① 积累·实干·循序

题型特征：材料讲"小事/碎片/点滴"积累成"大事"；时间利用；脚踏实地一步步来。常出现"余、毫末、足下、滴水、磨"等字眼。

立意通法：

  • 第一步：找"小→大"的递进链（如 毫末→合抱木、足下→千里）；
  • 第二步：确认材料褒"积累/坚持"而非"速成"；
  • 第三步：立意落"积累/脚踏实地/循序渐进/厚积薄发"。

通用素材库：董遇三余、齐白石三余、荀子"积善成德"、老子"合抱之木"、王羲之墨池、达·芬奇画蛋、司马迁忍辱著书。

变体考法：碎片时间利用→珍惜闲暇；终身学习→教师充电；厚积薄发→十年磨一剑；滴水穿石→持之以恒。

同类真题：2021下三余、2022下合抱之木（2025上沙漠种树含坚持面）。

类型② 辩证·对立统一

题型特征：材料出现对立两面（刚柔、黑白、进退、公私、顺逆）且强调"调和/转化/平衡"，不是非此即彼。

立意通法：

  • 第一步：找出对立两极 A 与 B（如 猛虎/蔷薇、白/黑）；
  • 第二步：看材料主张"并存调和"还是"相互转化"（甜加盐＝转化，刚柔＝并存）；
  • 第三步：立意落"刚柔并济/对立统一/辩证思维/反向思考/平衡"。

通用素材库：萨松猛虎蔷薇、太极阴阳、白加黑减、塞翁失马、老子"祸福相依"、张飞粗中有细、勾践卧薪尝胆（退→进）。

变体考法：反向思考→要想进可先退；过犹不及→适度；中庸→不偏不倚；平衡之道→快与慢、收与放。

同类真题：2022上猛虎蔷薇、2024下白加黑减、2025下钥匙与手机。

类型③ 创新·质疑·打破定式

题型特征：材料讲突破常规、发现错误、反常识成功；有人盲从权威有人敢破。

立意通法：

  • 第一步：找"常规/权威 vs 打破/质疑"的对照；
  • 第二步：看谁被褒（敢破者）、谁被贬（盲从者）；
  • 第三步：立意落"创新/勇于质疑/独立思考/打破思维定式"。

通用素材库：钢琴曲谱错误、荒漠高海拔种桃、哥白尼日心说、伽利略比萨斜塔、袁隆平杂交稻、爱迪生千次实验、商鞅变法。

变体考法：不迷信权威→经验可能成盲区；逆向思维→反常识成功；敢为人先→第一个吃螃蟹。

同类真题：2024上钢琴曲谱、2025上荒漠种桃（创新面）。

类型④ 合作·共赢·团结

题型特征：材料讲多方从对立/分散到协作、靠共同目标化解冲突。

立意通法：

  • 第一步：找"对立/竞争 → 合作/共赢"的转折点；
  • 第二步：定位转折的关键（共同目标、换位、沟通）；
  • 第三步：立意落"团队合作/和而不同/共赢共生"。

通用素材库：两队学生实验、廉颇蔺相如将相和、西游记师徒互补、蚂蚁过河、国际空间站多国合作、丝路通商。

变体考法：竞争中合作→竞合；团队精神→1+1>2；和而不同→君子之道。

同类真题：2023上竞争到合作。

类型⑤ 坚守·真理·耐寂寞

题型特征：材料讲好东西被埋没终被认可、长期坐冷板凳、真理迟到但不少到。

立意通法：

  • 第一步：找"被埋没/被忽视 → 终被承认"的脉络；
  • 第二步：确认材料褒"坚守原创、耐寂寞"而非追名；
  • 第三步：立意落"金子总会发光/耐住寂寞/坚守初心/真理不朽"。

通用素材库：孟德尔35年被埋没、曹雪芹十年增删红楼梦、司马迁忍辱写史记、梵高死后成名、屠呦呦青蒿素、陈景润摘数学皇冠。

变体考法：板凳甘坐十年冷→不慕虚名；守得云开见月明→坚持；真金不怕火炼→经得起检验。

同类真题：2023下孟德尔。

类型⑥ 担当·求知·家国

题型特征：材料讲志向使命、家国情怀，或对世界的好奇探究、追求真理。两种向量：向外（担当）与向内（求知）。

立意通法：

  • 第一步：分清材料是"向外担当"（家国社会）还是"向内求知"（真理探索），或两者并举；
  • 第二步：若并举，立"以担当立身、以求知致远"的结合式；
  • 第三步：立意落"志向担当/家国情怀/求知探索/追求真理"。

通用素材库：张载"四为"、范仲淹"先忧后乐"、林则徐"苟利国家"、钱学森归国、屈原"路曼曼其修远"、苏格拉底发问、陈景润探究。

变体考法：使命责任→立德树人；立志→志当存高远；家国情怀→小我融入大我。

同类真题：2026上四为与好奇。

2021下 · 三余读书类型①积累实干

材料细拆：材料一董遇"三余"——冬者岁之余、夜者日之余、阴雨时之余，皆用来读书；材料二齐白石借"鱼"谐音"余"自定三余——画者工之余、诗者睡之余、寿者劫之余。
要素：两人共同点＝把零碎闲暇用于精进本业（读书/作画/作诗）。
倾向：褒——善用闲暇、以余致精。
推导①（时间维度）：三余＝碎片时间 → 积小成多 → "珍惜闲暇、积少成多"。
推导②（热爱维度）：白石以余暇作诗画＝把热爱融生活 → "把热爱融入生活"。
推导③（教育维度）：教师亦需余暇精进 → "终身学习、教育与生活相融"。
推荐立意：①珍惜闲暇、积少成多（最稳，材料主线） ②把热爱融入生活 ③终身学习、教育与生活相融（教育向，教师考加分）。
主题词XX：积累终身学习坚持
开头示例（XX=积累）：钱塘江的潮水遵循着月球的引力，人类文明的每次升华都结合着积累的周期……积累，让无数个体实现了自我价值的升华，在时代洪流中找到自己的坐标。
教育联系：教师利用课余读书反思充电（终身学习）；引导学生善用零碎时间，滴水穿石。
遇类似题 → 见 类型①：凡"碎片时间/小事积累/水滴石穿"都往积累·坚持·循序靠。

2022上 · 猛虎细嗅蔷薇类型②辩证

材拆细拆：材料一萨松"In me the tiger sniffs the rose"——猛虎=刚/进取，蔷薇=柔/细腻，细嗅=两者调和；材料二时代迅疾变化，旧习惯与新规则并存，有人无动于衷/手足无措，有人与时俱进驾轻就熟。
要素：猛虎与蔷薇＝人性刚柔两面；旧与新＝时代变局。两材料共指"如何对待两极"。
倾向：辩证——赞调和统一、赞与时俱进。
推导①（人性调和）：猛虎+蔷薇＝刚柔并存 → "刚柔并济、人性调和统一"。
推导②（时代变局）：旧习惯+新规则 → 顺变者通 → "与时俱进、破旧立新"。
推导③（合一）：以刚柔并济的心态面对新规则 → 两者可合论。
推荐立意：①刚柔并济、人性的调和统一 ②与时俱进、破旧立新（两材各取一条最稳，也可合论"以刚柔之道应万变"）。
主题词XX：刚柔并济与时俱进调和
开头示例（XX=刚柔并济）：人类文明的每次升华都结合着刚柔并济的周期……刚柔并济，让无数个体实现了自我价值的升华，在时代洪流中找到自己的坐标。
教育联系：教师严慈相济＝刚柔；教育理念与时俱进，不拘旧法。
遇类似题 → 见 类型②：凡"对立两面+调和/转化"都往辩证·对立统一靠。

2022下 · 合抱之木生于毫末类型①积累实干

材料细拆：《老子》合抱之木生于毫末、九层之台起于累土、千里之行始于足下；《中庸》行远自迩、登高自卑。两段共证"大由小起、远由近始"。
要素：毫末→合抱木、累土→九层台、足下→千里、迩→远、卑→高，五组小大递进。
倾向：褒——积累、循序、踏实。
推导①：量变积累成质变 → "注重积累、脚踏实地"。
推导②：远行必自近 → "循序渐进、步步为营"。
推导③：戒骄戒躁、忌一步登天 → "厚积薄发"。
推荐立意：①注重积累、脚踏实地、循序渐进（最稳） ②厚积薄发 ③千里之行始于足下（务实向）。
主题词XX：积累脚踏实地循序渐进
开头示例（XX=脚踏实地）：人类文明的每次升华都结合着脚踏实地的周期……脚踏实地，让无数个体在时代洪流中找到自己的坐标。
教育联系：教育是慢功夫，循循善诱；学生成长循序渐进，忌拔苗助长。
遇类似题 → 见 类型①。

2023上 · 从竞争到合作类型④合作共赢

材料细拆：两队相似孩子，先随机分队各自活动→竞争性比赛→激烈冲突；再被设定共同目标（解决饮水短缺、推泥沼卡车）全员协作→冲突消除。
要素：竞争→对立；共同目标→协作→化解。转折点是"共同目标＋全员参与"。
倾向：贬恶性竞争，褒合作共赢。
推导①：竞争生对立 → "恶性竞争不可取"。
推导②：共同目标把对手变伙伴 → "合作共赢、团结协作"。
推导③：和而不同 → "竞争中寻找共生"。
推荐立意：①合作共赢、团结协作（最稳） ②化干戈为玉帛、和而不同 ③竞争中寻找共生。
主题词XX：合作团结共赢
开头示例（XX=合作）：人类文明的每次升华都结合着合作的周期……合作，让无数个体在时代洪流中找到自己的坐标。
教育联系：合作学习、小组探究；培养团队精神与社交能力。
遇类似题 → 见 类型④。

2023下 · 孟德尔被埋没的真理类型⑤坚守真理

材料细拆：孟德尔1865年发表《植物杂交实验》提出规律，数据准确结论新颖，却无人问津；1900年德弗里斯、柯伦斯、丘歇马克三人几乎同时独立重新发现才引起关注，且三人都承认孟德尔更早更深入。
要素：真理被埋没35年；终被承认；后人尊崇首创者。
倾向：褒——真理不朽、坚守原创、耐寂寞。
推导①：好成果被忽视多年仍被确认 → "是金子总会发光、真理不怕被埋没"。
推导②：默默耕耘35年 → "耐住寂寞、坚守初心"。
推导③：不逐名利做真学问 → "板凳甘坐十年冷"。
推荐立意：①是金子总会发光、真理不怕被埋没（最稳） ②耐住寂寞、坚守初心 ③板凳甘坐十年冷、不慕虚名。
主题词XX：坚守耐住寂寞初心
开头示例（XX=坚守）：人类文明的每次升华都结合着坚守的周期……历史反复验证——能穿透至暗时刻的，从来不是幸运的闪电，而是坚守铸就的永恒曙光。
教育联系：教师坚守教育规律、耐得住清贫寂寞；相信每个学生潜力"总会发光"。
遇类似题 → 见 类型⑤。

2024上 · 钢琴曲谱的错误类型③创新质疑

材料细拆：钢琴教师发现常练的《勃拉姆斯随想曲》有印刷错误，让学生停下纠正，学生答"我就是按谱弹的"；教师又找一批钢琴家视谱找错，不论资历深浅，演奏多遍都找不出错误。
要素：曲谱（权威）有错；学生盲从"按谱弹"；资深钢琴家也被经验束缚找不出。
倾向：贬——盲从权威、经验成盲区。
推导①：权威谱子有错却无人疑 → "勇于质疑权威"。
推导②：经验越深越找不出 → "经验可能成为盲区、打破思维定式"。
推导③：不唯书不唯上 → "独立思考"。
推荐立意：①勇于质疑权威、打破思维定式（最稳） ②经验可能成为盲区 ③独立思考、不唯书。
主题词XX：质疑独立思考打破定式
开头示例（XX=质疑）：人类文明的每次升华都结合着质疑的周期……能穿透至暗时刻的，从来不是幸运的闪电，而是质疑铸就的永恒曙光。
教育联系：培养学生批判性思维与质疑精神；教师不迷信教材教参，敢于修正。
遇类似题 → 见 类型③。

2024下 · 白加黑减类型②辩证

材料细拆：摄影术语"白加黑减"——拍亮（白）场景反要加曝光、拍暗（黑）场景反要减，反初学者常识；生活中类似"要想甜加点盐、要想顺设点难、要想紧放点宽、要想进可先退"。
要素：甜与盐、进与退、亮与加、暗与减，皆"对立面相互成全"。
倾向：辩证——反向思考、对立统一。
推导①：反其道而行得善果 → "反向思考、辩证思维"。
推导②：对立面相成 → "对立统一"。
推导③：度与分寸 → "过犹不及、张弛有度"。
推荐立意：①辩证思维、反向思考（最稳） ②对立统一、过犹不及 ③以退为进、张弛有度。
主题词XX：辩证反向思考对立统一
开头示例（XX=辩证）：人类文明的每次升华都结合着辩证的周期……辩证，让无数个体在时代洪流中找到自己的坐标。
教育联系：因材施教（辩证看学生）；宽严相济、张弛有度。
遇类似题 → 见 类型②。

2025上 · 荒漠种桃与沙漠造林类型③创新＋类型①积累

材料细拆：材料一农民"土专家"在海拔600米（常规500米以下）荒山试种出优质脆桃带农致富；材料二一家人库布齐沙漠治沙造林，屡栽屡败仍接着栽，终种活近千亩成林。
要素：材料一=打破海拔常规→创新突破；材料二=屡败屡栽→坚持积累。两材合一"创新+坚持"。
倾向：褒——创新突破、坚持不弃。
推导①（创新主线）：海拔超越常规却成功 → "打破思维定式、创新突破"。
推导②（坚持主线）：沙漠多次失败仍坚持 → "坚持不放弃、迎难而上"。
推导③（合论）：以创新破局、以坚持成事 → "创新＋坚守"。
推荐立意：①打破思维定式、创新突破 ②坚持不放弃、迎难而上（任选一条为主线，或合论"以创新破局、以坚守成事"，这样能覆盖两材更稳）。
主题词XX：创新坚持突破
开头示例（XX=创新）：人类文明的每次升华都结合着创新的周期……创新，让无数个体实现了自我价值的升华。
教育联系：教育方法创新、因人施策；教师坚守育人、迎难而上。
遇类似题 → 见 类型③＋类型①。

2025下 · 钥匙与手机类型②辩证

材料细拆：钥匙开私人空间让人回隐秘之地，但私人空间也难有完全隐私；手机是打开公共空间的钥匙让人走向外部，但通讯录满、真正联系的人却很少。
要素：钥匙=向内（私密），手机=向外（连接）；两端都有缺憾——隐私不全、连接不真。
倾向：辩证——反思数字时代人际与自我安顿。
推导①：私与公两端失衡 → "守护精神家园与构建真实连接相平衡"。
推导②：数字时代自我迷失 → "数字时代的自我安顿"。
推导③：连接虽多真实甚少 → "重拾真实、回归本心"。
推荐立意：①守护精神家园与构建真实连接相平衡（最稳，扣两端） ②数字时代的自我安顿 ③重拾真实、回归本心。
主题词XX：真实连接平衡回归本心

2026上 · 四为之志与好奇求知类型⑥担当求知

材料细拆：有人秉承张载"为天地立心，为生民立命，为往圣继绝学，为万世开太平"的志向，把人生与社会发展紧密相连；有人沉醉学术研究，怀极大好奇心向世界发问、探究万事万物为何如此。
要素：张载四为＝向外担当（家国社会）；学者好奇心＝向内求知（真理探索）。两材并举两种姿态。
倾向：褒——家国担当、求知探索。
推导①（担当线）：四为之志 → "志向与担当、家国情怀"。
推导②（求知线）：好奇心探究 → "求知与探索、追求真理"。
推导③（合论）：以担当立身、以求知致远 → 两者互补并举。
推荐立意：①以担当立身、以求知致远（合论最稳，扣两材） ②志向与担当、家国情怀 ③求知与探索、追求真理（单写一条亦可）。
主题词XX：担当求知家国情怀
开头示例（XX=担当）：人类文明的每次升华都结合着担当的周期……担当，让无数个体实现了自我价值的升华，在时代洪流中找到自己的坐标。
教育联系：教师使命担当（立德树人）；培养学生求知欲、探究精神与家国情怀。
