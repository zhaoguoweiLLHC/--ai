# 中学教师专业标准（试行）· 解析

> 来源：外部资料/301_综合素质/《中学教师专业标准》.pdf
> 转录日期：2026-09-07

## 一、基本理念

1. **师德为先**：热爱教育事业，践行社会主义核心价值体系，关爱中学生，为人师表，教书育人。
2. **学生为本**：尊重中学生权益，以中学生为主体，调动主动性，提供适合的教育，促进全面发展。
3. **能力为重**：把学科知识、教育理论与教育实践有机结合，突出教书育人实践能力；坚持实践、反思、再实践、再反思。
4. **终身学习**：学习先进教育理论，了解国内外教育改革经验，优化知识结构，做终身学习的典范。

## 二、基本内容

### 维度一：专业理念与师德

- **（一）职业理解与认识**：贯彻教育方针政策，热爱教育事业，认同教师专业性和独特性，团队合作。
- **（二）对学生的态度与行为**：尊重独立人格，平等对待，尊重个体差异，信任学生。
- **（三）教育教学的态度与行为**：育人为本德育为先，尊重教育规律，激发求知欲，引导自主学习。
- **（四）个人修养与行为**：富有爱心责任心耐心细心，乐观向上，善于自我调节，勤于学习，衣着得体。

### 维度二：专业知识

- **（五）教育知识**：掌握中学教育基本原理和方法，掌握教育心理学基本原理，了解中学生身心发展规律。
- **（六）学科知识**：理解所教学科知识体系、基本思想与方法，掌握课程标准，了解与其它学科联系。
- **（七）学科教学知识**：掌握所教学科课程标准，掌握学科教学方法，了解学生认知特点。
- **（八）通识性知识**：具有相应的自然科学和人文社会科学知识，了解中国教育基本情况。

### 维度三：专业能力

- **（九）教学设计**：科学设计教学目标和教学计划，合理利用教学资源和方法，引导个性化学习计划。
- **（十）教学实施**：营造良好学习环境，启发式探究式讨论式参与式教学，有效调控教学过程，整合现代教育技术。
- **（十一）班级管理与教育活动**：建立良好师生关系，结合学科教学育人，组织开展德育活动和身心健康活动。
- **（十二）教育教学评价**：利用评价工具，掌握多元评价方法，多视角全过程评价，引导学生自我评价，自我评价教育教学效果。
- **（十三）沟通与合作**：与学生、同事、家长、社区有效沟通合作。
- **（十四）反思与发展**：主动收集分析信息不断反思，针对问题进行探索研究，制定专业发展规划，参加专业培训。

## 三、实施建议

1. 教育行政部门：作为队伍建设基本依据，深化教师教育改革。
2. 教师教育院校：作为培养培训主要依据，科学设置课程。
3. 中学：作为教师管理重要依据，制定专业发展规划，开展校本研修。
4. 中学教师：作为自身专业发展基本依据，制定自我专业发展规划，大胆实践，不断创新。

## 考试相关要点

- **基本理念四条**：师德为先、学生为本、能力为重、终身学习（最常考）
- **三个维度**：专业理念与师德、专业知识、专业能力
- **十四个领域**：职业理解、对学生态度、教育教学态度、个人修养、教育知识、学科知识、学科教学知识、通识性知识、教学设计、教学实施、班级管理、教育教学评价、沟通与合作、反思与发展
- 课标P104-105提到"以《中学教师专业标准》的理念为指导"，即指上述四条基本理念
