## 弹性规则
1. 公司不足 3h：先保"大题/整卷"，选择题砍到周末。
2. 周末崩盘：不补重活，通勤多听一遍兜底。
3. 只练不改不长分：作文/立意必对答案或发 AI 批改。
4. 周末家用电脑：先同步本周新资料再开工——
   - 首次：git clone https://github.com/zhaoguoweiLLHC/--ai.git
   - 之后每次：进文件夹 git pull（没装 git 就到 GitHub 网页下 zip）
   - 老师每讲完一套题会自动 commit+push，pull 即是最新。
