二、弹性规则

  1. 公司不足 3h：先保整卷/大题，选择题砍到周末。
  2. 周末崩盘：不补重活，通勤多听一遍兜底。
  3. 早通勤听记性最好：新框架第一遍放早上；晚上读材料当预习。
  4. 只练不改不长分：作文/立意必对答案或发 AI 批改。
  5. 周末家用电脑：先 git pull 同步本周新资料再开工（首次 git clone；没装 git 就到 GitHub 网页下 zip）。
